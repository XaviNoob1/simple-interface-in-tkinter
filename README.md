# 🧮 Simple Interface in Tkinter

Una aplicación sencilla creada con **Python** y **Tkinter** que permite calcular el **área de diferentes figuras geométricas** (rectángulo, triángulo y círculo) mediante una interfaz gráfica limpia, colorida y fácil de usar.

---

## 🚀 Características principales

- 🎨 Interfaz gráfica creada con **Tkinter**  
- 📏 Cálculo de áreas de:
  - Rectángulo
  - Triángulo
  - Círculo
- 🖼️ Soporte para imágenes de cada figura  
- 🧩 Uso de **Frames**, **Buttons**, **Labels** y **Radiobuttons**  
- 🧠 Validación de errores con `messagebox`  
- 🌈 Colores personalizados y diseño estructurado

---

## 🧰 Tecnologías usadas

- **Python 3.x**
- **Tkinter** (interfaz gráfica)
- **Pillow (PIL)** para manejo de imágenes
